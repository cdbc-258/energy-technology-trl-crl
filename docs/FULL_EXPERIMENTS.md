# TRL/CRL消融与灵敏度

pipelines/full_nmf/experiments.py使用当前F主题映射，调用pipelines/nmf500/experiments.py中的共用证据实验引擎。

对122个对象执行724个情景，包括来源／引文／观测留一、来源类型消融、逐轴与逐门槛支持撤回、证据可用日期、Top1/Top3和余弦／差距敏感性。

撤回必要支持只降低证据支持或置为未知，不删除标准必要条件、不无故升级，并检查两轴独立。逐对象脆弱性关联当前主题与热点分数。

证据撤回采用保守规则，不自动对剩余证据重新进行语义裁定。可用日期有限，较早截止日期产生未知不能解释为技术退步。全量关联不意味着每条文献都具有成熟度证据。

结果在assets/full_nmf500/experiments，绑定当前分类、映射和证据哈希。
