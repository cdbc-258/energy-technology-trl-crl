# 当前处理方法

## 1. 主题、方向与评价对象

当前目录为500个论文NMF主题，组织5,119,004条冻结来源记录，其中5,104,807条已归类、14,197条未归类。391项为候选技术方向，122项为有界评价对象；主题、方向及对象仍需独立核验。

主题可含材料、算法、设备、政策等不同内容；方向也可含不同技术路线。评价需进一步限定：技术载体及配置、目标功能、集成范围、使用环境、证据时期。一个论文配方不能继承同方向商用设备的成熟度。一个整机案例也不能直接给所有材料和组件赋相同等级。

`case_technology_links.json`明确对象与方向的关系。`route_under`为具体路线，`models_for`等为模型、测试或组件支持关系，`system_realization_of`、`product_from_route`为整机或产品实现关系。所有关联均不自动传递等级。

## 2. 证据采集与核读

新闻检索、政府技术指南、机构库开放论文、项目运行报告、厂家和用户信息提供候选资料。493项定向新闻检索获得6,422条新闻条目、5,154个去重新闻链接，仅表示检索范围，不能等同于493个目标均已完成实质评审。

接受证据前，核对以下内容：

1. 标题、DOI、型号、配方和项目是否对应同一对象。
2. 所述是实际完成事件、计划、额定规格、估算还是模拟结果。
3. 技术验证的载体、集成和环境是否匹配所评阶段。
4. 商业证据中的供需方、履约结果和期间是否可识别。
5. 来源是否存在利益相关性、日期缺失、单位错误或相反信息。

有效引文记录原文字符区间、原文正文哈希、引文哈希与URL。原文正文哈希用于来源追踪，公开仓库仅收录必要引文，因此离线验证不宣称重新核验整个远端正文。发布日期未知保留为空，不能用抓取日伪造历史发布日期。证据晚于截止日期不得使用。

## 3. TRL：Q/GDW 12566—2025

依据《技术成熟度评价方法》第5章及第6章表1，参考附录A—D。标准要求开展技术分解、确定关键技术清单，按技术状态、集成状态、试验环境制定评价细则，再开展自评及独立专家评审。

|TRL|定义要点|证据检查重点|
|---:|---|---|
|1|发现支撑研发的基本原理|原理与目标技术关联|
|2|提出基本原理的应用设想|具体应用、功能与场景|
|3|关键功能通过理论可行性验证|路线、方案和理论验证|
|4|系统关键技术得到实验环境验证|明确关键功能、实验/仿真环境与完成结果|
|5|关键部件完成功能测试|部件或分系统集成、模拟使用环境、测试达到相关要求|
|6|原型样机通过验证|原型、关键集成、相应使用条件、关键功能及性能验证|
|7|工程样机通过型式试验|工程型号、典型环境、型式/软件工程测试和性能验证|
|8|产品挂网试运行|系统级产品或软件上线，并完成全面测试|
|9|产品应用|具备规模化推广应用条件的工程产品|

上述门槛在代码中展开为可核查项目，不以论文数量、被引或专利数量替代标准要求。TRL5—7涉及“合格”的判断，需事先定义要求、测试方法与实际结果；不能观察到一个最佳值后把它倒设为合格阈值。明确质性目标也需对应方法和达成原文。TRL9关注实际工程功能和推广条件；批量完成应用可作为证据，未来产能计划不能替代。

输出值是**最高已核读且全部门槛获支持的证据阶段**，不是实际成熟度的绝对上限，也不代表逐个历史阶段及正式程序均已完成。

## 4. CRL：招标定义与调研细化

项目招标书《电网情报面板招标书_v1》定义CRL五级，并提出市场规模、产业参与、资本活跃、政策环境、应用示范、技术经济六维指标。

参考ARENA《Commercial Readiness Index for Renewable Energy Sectors》PDF第5—7页的市场证据与指标框架：
https://arena.gov.au/assets/2014/02/Commercial-Readiness-Index.pdf

ARENA使用六级CRI。这里只借鉴证据维度与“单项目不自动代表整个行业”的原则，不采用其数字等级映射，也不以它的TRL定义替代Q/GDW。

以下证据要求为本项目的操作规则，需进一步专家审定；不是Q/GDW的CRL规定：

|CRL|招标定义|当前操作要求|
|---:|---|---|
|1|无商业化活动|有明确对象、期间和活动范围内的直接无商业活动证据|
|2|市场探索|具体用户和需求、已发生试用或商业模式验证、用户价值反馈|
|3|早期市场进入|可识别供需主体、实际供货/销售/许可/商业工程履约、期间与结果|
|4|规模化商业应用|持续重复交付、交付运维能力、可核实持续商业经济性|
|5|市场成熟与主导地位|细分市场与时间分母、主导性和成熟市场证据、持续竞争经营能力|

没找到销售资料不能证明CRL1。专利申请或授权不独立决定CRL；只有同对象许可、转让或产品交易的实际履约才能提供相应商业证据。商业意向、未来订单、预计回收期、融资额、合成价格收入不能直接证明销售、持续盈利或市场主导。

只有技术提供单位名称及用户节能效果而没有明确交易履约的案例通常支持市场探索。BOT、EMC、直接合同及已完成商业服务可支持早期进入，但公开初评不等于已核验私有合同原件或回款审计。

## 5. 独立计算与缺项

两轴分别运行。每个阶段全部门槛为`met`才可通过；`unknown`为缺证据，`not_met`需直接不满足证据，`conflict`为未解决矛盾。未解决反证阻止通过，计划不能按已完成事件判级。

技术档案哈希绑定门槛审阅，档案改变后需重新核读。每个观测必须引用同对象、同范围的已接受证据。只有同一对象两轴有值才进入二维坐标，不能把一项技术的TRL与另一项技术的CRL拼接。

391方向只报告相关案例及分布，不取案例最大值或均值给方向赋统一等级。所列17条工程/商业量化事实分清实际、额定、年化估算和未来目标，不冒充完整招标指标矩阵。

## 6. 当前结果的性质

当前未完成全部对象的关键风险清单、专属细则审定、自评和独立专家流程；正式等级为空。招标书36项指标完整采集、AHP等权重审定、阈值标定和综合分计算尚不齐备，不生成加权成熟度分数或验收达标结论。

代码能够重现基于已审判据的数值并检查数据一致性，不能取代技术专家语义判断或独立试验。供应商自述、政府案例汇编和作者论文的证据强度不同，具体限制见来源与对象记录。
